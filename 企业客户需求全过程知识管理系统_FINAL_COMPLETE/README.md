# 企业客户需求全过程知识管理系统（模拟数据集）

本目录包含三套彼此独立但可组合验收的模拟项目：

1. `华东新程汽车项目`：企业采购知识管理软件项目，重点展示沟通、会议、文档、决策与 RAG 上下文。
2. `东辰出行新能源车辆采购项目`：100 台新能源车辆采购项目，重点展示从客户需求到方案、寻源、商务、合同、VIN 履约、验收、结算、售后和复盘的完整业务链。
3. `星瀚汽车动力电池智能招采项目`：汽车制造集团采购 12,000 套动力电池包的黄金验收集，完整覆盖采购预算、计划、立项、方案、执行、合同、归档、供应商管理和统计分析，同时提供原始证据、Requirement Truth、权限与时间语义、供应商画像、文档审查、RAG、机器评测和隔离的负向样本。

## 重要声明

目录内所有企业、人员、统一社会信用代码、VIN、报价、合同、金额、时间、验收结果、满意度与复购信息均为模拟演示数据（`synthetic_demo`），不代表任何真实企业、交易或业务成果。晚于数据制作日期的交付、结算和售后记录属于未来剧本式模拟（`simulated_future_scenario`），不表示事件已经发生。

## 建模原则

- 以 `Requirement` 为中心对象，用 `requirement_version_id` 固化每次需求变化。
- 报价、采购方案、合同和订单必须关联已确认需求基线。
- 车辆业务从订单级下沉到唯一模拟 VIN，可追溯供应商、采购单、销售订单、物流、交付、验收和售后。
- 同时组织需求流、商品流、商务流、资金流和信息流。

## 完整车辆采购演示入口

从 `03_客户项目全过程库/东辰出行新能源车辆采购项目/project_master.json` 开始，按其中 `dataset_files` 顺序读取各阶段文件。

## 采购知识管理软件项目入口

从 `03_客户项目全过程库/华东新程汽车项目/project_master.json` 开始。该项目包含三条版本化需求、十二场阶段会议、十二条企微、六封正式邮件、八份业务文档以及按真实来源重建的RAG索引。

`04_沟通记录` 是该项目唯一沟通来源目录；`05_业务文档` 仅存放正式业务资料。RAG中的知识块数量代表独立来源语义，不通过复制相同正文制造规模。

## 汽车制造智能招采黄金验收入口

从 `03_客户项目全过程库/星瀚汽车动力电池智能招采项目/project_master.json` 开始。该项目把原始证据、结构化需求真相和带ACL的RAG知识块组成三层闭包，并提供5家不同风险特征的模拟供应商、10份文档审查黄金样本、54条上下文沟通、36条机器可判分问题和4套独立异常场景。负向样本位于 `adversarial/`，不得并入黄金案例的合同、财务、供应商排名或统计结果。
