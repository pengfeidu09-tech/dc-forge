# 星瀚汽车动力电池智能招采项目（黄金验收集）

本项目是与智能招采一体化平台业务主链对齐的合成黄金案例。模拟星瀚汽车制造集团为2027款纯电平台采购12,000套磷酸铁锂动力电池包，依次完成采购预算、采购计划、项目立项、采购方案、采购执行、采购合同、文件归档、供应商管理和统计分析，并在过程中使用文档生成、规则审查、制度问答、供应商画像和权限控制能力。

所有企业、人员、供应商、报价、资质、合同、履约、风险、诉讼和指标均为 `synthetic_demo`。晚于2026-08-14的记录属于 `simulated_future_scenario`，不表示事件已经发生。PPT中的60%、50%、95%、6倍、86%等数字只保存在外部资料索引中，统一标记为未经验证的营销声明，不是本项目结果。

## 使用方式

先读取 `project_master.json`，再按九阶段文件理解结构化业务对象。需求理解和RAG验收使用 `00_原始证据`、`02_采购立项与需求/requirement_truth.json` 和 `10_RAG/golden_chunks.jsonl` 三层闭包。权限和时间点查询使用 `08_权限与时间/security_model.json`。机器判分问题位于 `11_评测集/eval_cases.jsonl`。

`valid/` 语义由项目根目录表示；`adversarial/` 下四套变体故意包含冲突、过期、拒绝和对账错误，不得与黄金案例汇总。

## 验收数据清单

- 26份彼此独立的原始证据，覆盖电话转写、会议原文、邮件、预算、制度、招标、供应商资质与风险材料；
- 52条客户确认的Requirement Truth，其中包含9个无悬空引用的现状流程节点和5个可定位痛点；
- 5家按时间、工厂和品类限定的供应商画像，覆盖证书过期、诉讼、质量、交付和信用风险；
- 4份控制文档与6份故意植入问题的审查样本；
- 54条带前后文、来源和业务对象关联的沟通记录；
- 27条带双时态、ACL、字段脱敏和权限版本的RAG知识块；
- 36条覆盖事实、追因、时间点、证据不足、越权、脱敏、文档审查、供应商分析和异常识别的机器评测题。

以上数量是本地模拟验收语料的文件与对象计数，不是AI准确率、效率提升或真实业务成果。
