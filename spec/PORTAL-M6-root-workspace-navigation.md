# PORTAL-M6：根门户业务工作台导航

## 背景

根页面 `/` 只提供企业知识门户内部视图切换，没有暴露独立售前工作台 `/presales/workbench` 的入口。用户必须事先知道 URL，无法从门户完成业务页面发现和跳转。

## 目标

- 在根门户侧边栏增加明确的“业务工作台”分组。
- 提供可直接访问 `/presales/workbench` 的“售前协作工作台”链接。
- 入口使用原生链接语义，支持复制地址、在新标签页打开和键盘访问。
- 桌面和窄屏侧栏均保留可识别的入口图标。

## 非目标

- 不引入前端路由库。
- 不改变根门户现有内部视图状态和业务接口。
- 不为必须携带项目 ID 的客户页面编造通用入口。

## 验收标准

1. 根门户源码包含“业务工作台”导航分组。
2. “售前协作工作台”通过真实链接指向 `/presales/workbench`。
3. 链接复用侧栏导航的交互样式，并具备清晰的悬停和键盘焦点状态。
4. 根门户既有测试、前端构建和 `tests/test_contracts.py` 通过。
